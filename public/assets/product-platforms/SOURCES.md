# Platform icons

Copied without editing vector geometry from the installed `simple-icons` package, version 16.31.0, `icons/{x,reddit,youtube,github,telegram}.svg`.

- Package source: https://github.com/simple-icons/simple-icons
- Package license: CC0-1.0. Brand marks remain marks of their respective owners; inclusion does not indicate affiliation.
- UI renders these vectors as CSS masks, with contextual brand colors or mineral white.
- Website, News, Filings, People and the generic feed icon are ordinary interface symbols authored as inline SVG in `PlatformIcon.tsx`; they are not corporate logos or generated raster images.

No remote icon service or runtime third-party request is required.
