# OMNIA EYE — Frontend Design

Public motion study for [OMNIA EYE](https://eyeomnia.com), an intelligence interface built to connect scattered market signals before they become consensus.

This repository contains a deliberately bounded visual slice: the signal field, the observation lens, and the transition from fragmented updates to a structured insight. The production application, data pipeline, complete cinematic journey, proprietary assets, and account experience are maintained separately.

## Run locally

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
npm run preview
```

## Included

- Responsive canvas signal field
- Scroll-linked observation lens
- Accessible HTML insight layer
- Reduced-motion mode
- Desktop and mobile layouts
- No production APIs, credentials, databases, tracking, or private assets

## Design direction

Mineral white typography, graphite surfaces, emerald focus, and quiet geometric motion. The interface keeps the source material legible while using depth and movement to show how separate events become one connected view.
